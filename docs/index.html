Getting started

Welcome to Mercury Schema

Mercury Schema adds schema markup to your WordPress site: small labels that tell Google, Bing and AI assistants exactly what each page is about. You don't need to write any code.

What is schema markup?

When a person reads your recipe page, they can see the cooking time and the ingredients. A search engine sees a page of text. Schema markup spells out the details in a format search engines understand: "this is a recipe, it takes 25 minutes, it serves 4".

Search engines use these labels to show rich results: search listings with extras such as star ratings, prices, event dates or cooking times. Rich results stand out, so more people tend to click them.

sunrisebakery.example › recipes › pancakes
Classic Fluffy Pancakes
★★★★★4.8 (126 reviews)·25 min·320 cal
Light, fluffy pancakes made with buttermilk. Ready in under half an hour…

An example search result. The rating, cooking time and calories come from Recipe schema.

Note

Schema makes your pages eligible for rich results. Google decides when to show them, and it can take a few days or weeks after Google next visits your page.

What Mercury Schema does for you

  • Sets up the basics automatically. A one-minute setup adds your organization, website, page details and breadcrumbs to every page.
  • Fills in details for you. New schemas take the title, date, author and featured image from your post, so most fields are already done.
  • Never publishes broken markup. If a required detail is missing, the schema is marked Incomplete and kept off your site until you fill it in.
  • Stays light. No extra scripts or styles are loaded on your site, so pages don't get slower.
  • Works with your tools. The block editor, the classic editor, Elementor and WooCommerce.

Getting started

Install the plugin

Mercury Schema comes as a single zip file. You upload it to WordPress the same way as any other plugin.

Download the plugin

Download Mercury-Schema.zip. This link always gives you the newest version.

Important

Don't unzip the file. WordPress needs the zip exactly as you downloaded it. Some Mac browsers unzip downloads automatically; if you see a folder instead of a zip, use the zip in your Trash or turn off "Open safe files after downloading" in Safari.

Upload it to WordPress

  1. In your WordPress dashboard, go to Plugins › Add New Plugin.
  2. Click Upload Plugin at the top of the page.
  3. Click Choose File, pick Mercury-Schema.zip, then click Install Now.
  4. When the upload finishes, click Activate Plugin.

WordPress takes you straight to the Mercury Schema setup wizard. Carry on with Run the setup wizard.

Finding Mercury Schema later

Mercury Schema has its own blue item in the left-hand menu of your dashboard.

Updating to a new version

  1. Download the latest Mercury-Schema.zip from the same link.
  2. Go to Plugins › Add New Plugin › Upload Plugin and upload it.
  3. WordPress asks whether to replace the current version. Click Replace current with uploaded.
Tip

Updating never deletes your schemas. Even deleting the plugin keeps them, so they come back if you install it again.

Getting started

Run the setup wizard

The wizard picks the right schema types for your site and adds the site-wide basics for you. It takes about a minute, and you can change everything later.

1. Getting Started

The wizard opens by itself after you activate the plugin.

2. Choose your schema setup

Pick one of three starting points.

Not sure?

Choose Smart. A type that's switched on does nothing until you use it, so having extra types on costs nothing.

3. Schemas (Custom only)

If you chose Custom, you now see every schema type with a switch.

4. Done

That's it. Mercury Schema is now adding schema to your site.

Running the wizard again

Go to Mercury Schema › Schema Types and click Run setup wizard again at the bottom of the page. Your schemas and settings stay as they are until you finish the wizard.

Using Mercury Schema

Choose your schema types

The Schema Types screen controls which kinds of schema your site uses. Switch on only what you need, so the list in the editor stays short.

Go to Mercury Schema › Schema Types.

Changes save straight away. You'll see a short confirmation in the corner of the screen.

What happens when a type is off

  • It no longer appears in the Add schema list in the editor.
  • Any schema of that type that you already added stops appearing on your site. It shows a Type off label in the editor.
  • Nothing is deleted. Switch the type back on and everything returns as it was.

Not sure which types you need? See Which schema type should I use?

Using Mercury Schema

Site-wide schemas

Site-wide schemas describe your whole website: who runs it, what it's called, and how pages fit together. You set them up once and they appear on every matching page.

Go to Mercury Schema › Site-wide Schemas. If you ran the setup wizard, five schemas are already here and marked Ready.

Add your logo and social profiles

The Organization schema tells search engines who is behind the site. It's the most useful one to complete.

  1. Click Organization to open it.
  2. Check the fields. Name, website, logo and description are filled in from your WordPress settings already.
  3. Add your Email and Telephone if you want them shown.
  4. In Profile URLs, paste the web address of each social profile, one per line.
  5. Click Save changes.
Tip

The logo comes from Appearance › Customize › Site Identity (or Appearance › Editor on block themes). If your theme has no logo set, paste the logo's address into Logo URL instead. You can copy it from the Media Library.

Choose where a schema appears

Open the Display rules tab to limit where a site-wide schema is added.

Below these you can also limit a schema to certain categories, to posts written by certain author roles, or to specific post IDs. Leave a group empty to mean "any".

Good to know

If a post has its own schema of the same type (for example its own Article), the post's version is used instead of the site-wide one on that page.

Using Mercury Schema

Add schema to a post or page

Use the Schema Markup box to add schema for one post or page, such as an FAQ, a recipe or a product. Here we add an FAQ to a blog post.

Find the Schema Markup box

Open any post or page for editing. The Schema Markup box is below your content. In the block editor you may need to scroll down, or drag the Meta Boxes bar up.

Can't see it?

Check that the post type is ticked under Settings, and that you're an Administrator or Editor. More fixes in the FAQ.

Choose a schema type

Click Add schema. Type in the search box to find a type, or click one from the list.

Types you switched off under Schema Types aren't listed. A type that's already on the page is marked Added.

Fill in the details

  1. Type your first question and its answer.
  2. Click Add question for each extra question.
  3. Click Save changes.

Fields marked with a red * are required. Everything else is optional, but the more you fill in, the more search engines know.

Important

The schema saves on its own when you click Save changes in the box. It doesn't wait for the post's Update or Publish button. Schema on a draft appears on your site once the post is published.

Check the status

After saving, the label at the top of the schema tells you whether it's working.

Using Mercury Schema

Dynamic values

Dynamic values are placeholders that fill themselves in from your post or site, like {{post_title}}. They keep your schema up to date when you edit the post.

Most new schemas already use dynamic values, which is why fields such as the headline and date are filled in for you. When you change the post title, the schema changes too.

Insert a dynamic value

  1. Click into a field where you want the value.
  2. Click the { } button at the right of the field.
  3. Choose a value from the list.

You can also mix your own text with a dynamic value, for example Recipe: {{post_title}}.

All dynamic values

ValueFilled in with
{{post_title}}The post or page title
{{post_excerpt}}The excerpt (the short summary in the post settings)
{{post_content}}The post text, without formatting
{{post_url}}The web address of the post
{{post_date}}The date the post was published
{{post_modified}}The date the post was last changed
{{featured_image}}The address of the featured image
{{author_name}}The author's display name
{{author_url}}The address of the author's post list
{{site_name}}Your site title (Settings › General)
{{site_description}}Your tagline (Settings › General)
{{site_logo}}The address of your site logo
{{home_url}}Your home page address
{{site_language}}Your site language, such as en-US

With WooCommerce active, six more values are available for products: price, currency, stock status, SKU, average rating and review count. See Elementor and WooCommerce.

Good to know

If a value is empty (for example a post with no excerpt), the field is left out. If that field is required, the schema shows as Incomplete until you fill it in some other way.

Using Mercury Schema

Elementor and WooCommerce

Mercury Schema works inside Elementor and reads product details from WooCommerce automatically.

Edit schema inside Elementor

  1. Open your page with Edit with Elementor.
  2. In Elementor's top bar, click the Mercury Schema M icon (Schema Markup).
  3. Add and edit schemas in the window that opens, exactly as described in Add schema to a post or page.
  4. Close the window with the × to get back to your design.
Good to know

Schema saves with its own Save changes button, separate from Elementor's Publish. On older Elementor versions you'll find Schema Markup in the Elementor menu (☰) instead of the top bar.

WooCommerce products

When WooCommerce is active, a new Product schema on a product fills itself in from the product: price, currency, stock status, SKU, average rating and number of reviews. When you change the price in WooCommerce, the schema follows.

  1. Check that Products is ticked under Mercury Schema › Settings, so the Schema Markup box appears on products.
  2. Open a product and add a Product schema.
  3. Check the fields and click Save changes.
Tip

Want every product covered without opening each one? Add a Product schema under Mercury Schema › Site-wide Schemas and set its display rules to the Product post type. Each product's own details are filled in automatically.

Ratings are only included once a product has at least one review.

Using Mercury Schema

Test your schema with Google

Google's free Rich Results Test shows which rich results a page qualifies for. Use it after adding schema to an important page.

  1. Make sure the page is published and visible to the public.
  2. In the schema's Preview tab, click Test in Google. Or go to search.google.com/test/rich-results and paste the page's address.
  3. Wait for the test to finish (usually under a minute).
  4. Look for green ticks next to each detected item, such as FAQ, Recipe or Breadcrumbs.

Reading the results

  • Valid items: everything is fine.
  • Warnings (orange): optional details are missing. The page can still get rich results; adding the details may help.
  • Errors (red): something must be fixed. Mercury Schema checks required fields before printing, so this is rare. Check the schema's Preview tab first.
Note

Some schema types, such as Organization, Website and Web Page, don't create a visible rich result. The test may not list them, but search engines still read them. You can see every schema on a page with the Schema Markup Validator.

Testing a site that isn't public yet

Google can't reach a site on your own computer or behind a password. Use the Copy button in the Preview tab, then paste the code into the Code tab of the Rich Results Test.

How long until rich results show up?

Google has to visit your page again before it notices new schema. That usually takes a few days to a few weeks. To speed it up, use URL Inspection › Request indexing in Google Search Console. Even then, Google decides when to show rich results.

A note on FAQ and How-To results

Google now shows FAQ rich results mostly for well-known government and health websites, and no longer shows How-To rich results. These schemas are still worth adding: search engines and AI assistants use them to understand your questions and instructions, even when no extra result appears.

Help

FAQ and troubleshooting

Answers to the questions people ask most. Click a question to open it.

Something isn't working

I can't see the Schema Markup box
  • Scroll below the post content. In the block editor, drag the Meta Boxes bar up, or open the ⋮ menu › Preferences › Panels and make sure Schema Markup is switched on.
  • Check that the post type is ticked under Mercury Schema › Settings.
  • Check your role. Only Administrators and Editors can edit schema.
My schema says Incomplete

A required field is empty, so the schema is kept off your site. Open the schema and look for the field outlined in red. Often it's a dynamic value with nothing to fill in, such as {{featured_image}} on a post without a featured image. See Fixing an Incomplete schema.

My schema says Type off

The schema type has been switched off under Mercury Schema › Schema Types. Switch it back on there. Your schema is still saved.

A schema type is missing from the Add schema list

It's switched off. Go to Schema Types and switch it on. The list also has a Manage schema types link at the bottom.

Breadcrumbs or Site Navigation don't appear on a page

These build themselves, and are only added when there's something to show. Breadcrumbs need a page below the home page; they aren't added to the home page itself. Site Navigation needs a menu on your site.

Google's test doesn't find my schema
  • Is the page published and public? Schema isn't added to drafts or password-protected content.
  • Is the schema Ready and its switch on?
  • Do the display rules allow this page? Check the Display rules tab.
  • Clear your caching plugin's cache, then test again.
I use Yoast, Rank Math or another SEO plugin. Will they clash?

Many SEO plugins add their own Organization, Website and Article schema. Having the same thing twice won't break your site, but it's tidier to have one source. Either switch those types off under Schema Types and let your SEO plugin handle them, or turn off the schema output in your SEO plugin. Use Mercury Schema for the types your SEO plugin doesn't offer.

General questions

Will Mercury Schema slow down my site?

No. It adds no scripts, styles or extra requests to your pages. Schema for a post is stored with the post, so WordPress already has it when the page loads.

Do I have to add schema to every post?

No. The site-wide schemas from the setup wizard already cover every page. Add schema to individual posts only for special content, such as an FAQ, a recipe, a product or an event.

Can I add more than one schema to a page?

Yes. For example, a recipe post can have a Recipe and an FAQ. Mercury Schema marks types already on the page as Added so you don't add one twice by mistake.

What happens if I deactivate or delete the plugin?

The schema stops appearing on your site straight away. Your saved schemas are kept in the database, so if you install Mercury Schema again they come back. Deleting the plugin removes only its settings.

Does it work with the classic editor?

Yes. The Schema Markup box appears below the content editor and works the same way.

I used UnlimitedSchema before. What happens to my schemas?

Mercury Schema is the new name for UnlimitedSchema. When you activate it, your schemas and settings move over automatically and the old plugin is deactivated. You can then delete UnlimitedSchema.
